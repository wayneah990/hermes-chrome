# Code of Conduct

This project follows a simple standard: be respectful.

- No harassment, hate, or personal attacks.
- No spam, drive-by vandalism, or malicious PRs (malware, token stealers, debugger abuse).
- Assume good faith on install questions; this stack (Hermes + Chrome MV3) is fiddly.

Maintainers may close or block anything that violates this. For serious abuse, see [SECURITY.md](SECURITY.md).
